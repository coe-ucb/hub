# Student Access Hub — GitHub Pages files

Upload every file and folder in this package to the root of a GitHub repository.

Then open the repository's **Settings → Pages** and select:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

Save the settings. GitHub will display the public website address after deployment finishes.

Do not remove the `assets` folder or `lucide.min.js`; the page uses them for the background, sharing image, and icons.
